# 🌊 Çanakkale Water and Energy Management SCADA & Decision Support System

This project is a **SCADA and Decision Support System (DSS)** prototype developed for efficient water and energy resource management, real-time meteorological tracking, and AI-powered operational optimization in Çanakkale.

🌐 **Live Demo:** [can-su.vercel.app](https://can-su.vercel.app)

---

## 🚀 About the Project
Designed to eliminate data complexity in traditional water and energy management systems and provide operators with intelligent recommendations. The system fetches external meteorological data in real-time to analyze energy potential and generate the most efficient operating schedule.

---

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Visualization:** Chart.js (Dynamic and interactive charts)
* **Data Source:** Open-Meteo API (Real-time Çanakkale weather and wind data)
* **Data Analysis & Simulation:** Python (Initial data processing and test scenarios)
* **Version Control & Deployment:** Git, GitHub, Vercel

---

## ✨ Key Features
* **Real-Time Weather Integration:** Fetching live meteorological data for Çanakkale via the Open-Meteo API.
* **Dynamic SCADA Panel:** Visualizing wind speed, energy consumption, and water optimization metrics using Chart.js.
* **AI-Powered Decision Support:** Optimization recommendations for running pumps and energy infrastructure during peak efficiency hours.
* **UI Enhancements:** Turkish/English language support, Dark/Light mode switching, and smart search filters.

---

## 📊 Architecture & Data Status
Weather and wind data used in the project are fetched live and in real-time via the **Open-Meteo API**. Water pump and valve controls are managed through scenario-based simulation (mock/placeholder) data for the prototype phase.
